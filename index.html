What is CalBridge?

A full-stack multi-tenant client portal for Amazon sellers and vendors — connecting advertising data, sales data, and contribution margin analytics in one place.

📊

Dashboard & KPIs

Real-time KPIs: Total ROAS, ACOS, Ad Sales, Contribution Margin (CM1/CM2/CM3 waterfall). Synced from Amazon APIs via Snowflake.

Dashboard API →
💡

Decision Engine

Auto-calculates break-even ACOS per ASIN. Surfaces danger alerts, over-pacing budgets, and scale opportunities. One-click actions coming soon.

Decisions API →
🔗

Amazon Integrations

OAuth connections for all 4 Amazon account types: Amazon Ads, DSP, Seller Central, Vendor Central. Tokens auto-refresh.

Amazon API →
🏥

Admin Health Scores

Per-client health scoring (0–100) based on CM trend, ACOS vs break-even, data freshness, connections, and login recency.

Visual Revenue → CM1 → CM2 → CM3 breakdown. See exactly where margin is lost at each step: COGS, FBA fees, and ad spend.
