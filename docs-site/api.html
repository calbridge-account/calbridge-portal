API Reference

Base URL: https://app.teamcalbridge.com · All endpoints require credentials: 'include' for session cookies.

Authentication

Session-based auth. All authenticated routes require an active session (set via /auth/login or /auth/signup).

POST /auth/signup

Create a new client account. Creates session on success.

Body
namestringrequired
emailstringrequired
passwordstringrequired, min 8 chars
POST /auth/signup { "name": "Acme Corp", "email": "acme@example.com", "password": "secret123" } → 201 { "message": "Account created", "client": { "id": "...", "email": "...", "name": "..." } }
POST /auth/login

Log in with email and password.

POST /auth/login { "email": "acme@example.com", "password": "secret123" } → 200 { "message": "Logged in", "client": { "id": "...", "email": "...", "name": "..." } } → 401 { "error": "Invalid credentials" }
GET /auth/me 🔒 Auth

Get the currently logged-in client.

GET /auth/me → 200 { "client": { "id": "...", "email": "...", "name": "..." } } → 401 { "error": "Authentication required" }
POST /auth/forgot-password

Request a password reset email. Always returns 200 (doesn't reveal if email exists).

POST /auth/reset-password

Set a new password using a valid reset token. Token valid for 1 hour.

tokenstringrequired
passwordstringrequired, min 8 chars

Amazon Connections

OAuth flows for all 4 Amazon integrations. Tokens are auto-refreshed on expiry.

GET /amazon/connect/:type 🔒 Auth

Redirect to Amazon OAuth consent screen. type: ads | dsp | seller | vendor

GET /amazon/status 🔒 Auth

Get connection status for all 4 Amazon integrations.

GET /amazon/status → 200 { "ads": { "connected": true, "label": "Amazon Ads", "connectedAt": "...", "expiresAt": "..." }, "dsp": { "connected": false, "label": "Amazon DSP" }, "seller": { "connected": true, "label": "Amazon Seller Central", "sellingPartnerId": "..." }, "vendor": { "connected": false, "label": "Amazon Vendor Central" } }

Dashboard

GET /dashboard/summary 🔒 Auth

Overview KPIs: retail sales, ad attributed sales, ad spend, ROAS, ACOS, and CM waterfall breakdown.

daysnumberdefault 30
GET /dashboard/summary?days=30 → 200 { "totalRetailSales": 42500.00, "sellerRevenue": 35000.00, "vendorRevenue": 7500.00, "totalUnits": 840, "totalAdSales": 18200.00, "totalAdSpend": 4200.00, "totalAdOrders": 320, "adRoas": 4.33, "acos": 0.231, "totalRoas": 10.12, "cmBreakdown": { "revenue": 42500, "cogs": 8500, "fbaFees": 6375, "adSpend": 4200, "cm1": 34000, // Revenue - COGS "cm2": 27625, // CM1 - FBA Fees "cm3": 23425 // CM2 - Ad Spend }, "days": 30 }
GET /dashboard/performance 🔒 Auth

Top and bottom performing ASINs by contribution margin.

daysnumberdefault 30
limitnumberdefault 10
GET /dashboard/sales-performance 🔒 Auth

Top 10 ASINs by revenue, daily sales trend, and Seller vs Vendor channel split.

GET /dashboard/sales-performance?days=30 → 200 { "topAsins": [ { "asin": "B001TEST01", "productName": "...", "units": 120, "revenue": 4500.00, "activeDays": 28 } ], "dailyTrend": [ { "date": "2026-03-01", "revenue": 1420.50, "units": 28 } ], "channelSplit": [ { "channel": "seller", "revenue": 35000, "units": 700 }, { "channel": "vendor", "revenue": 7500, "units": 140 } ], "days": 30 }
GET /dashboard/asin/:asin 🔒 Auth

CM trend for a specific ASIN over time.

POST /dashboard/sync 🔒 Auth

Manually trigger a full data sync for the logged-in client (runs in background).

Decisions

GET /decisions 🔒 Auth

Run the decision engine and return insights, alerts, and recommendations. Includes budget pacing alerts.

GET /decisions?days=30 → 200 { "summary": { "totalAsins": 12, "losingMoney": 2, "overSpending": 3, "opportunities": 1, "alertCount": 5 }, "insights": [ { "type": "danger", "category": "negative_margin", "title": "B001TEST03 is losing money", "message": "CM3 is -$42.00 (-8.4%) — spending more than earning", "action": { "label": "Reduce Ad Spend", "type": "reduce_budget", "asin": "B001TEST03" } }, { "type": "warning", "category": "budget_overpacing", "title": "Budget Over-Pacing", "message": "Over-pacing: projected to overspend by 18.3% ($2,180 vs $1,840 budget)" } ] }

Advertising

GET /advertising/overview 🔒 Auth

Advertising overview: total spend, sales, ACOS, ROAS, impressions, clicks, daily trends.

daysnumberdefault 30
GET /advertising/campaigns 🔒 Auth

Campaign-level performance breakdown with ACOS, ROAS, spend, and sales per campaign.

Campaigns

GET /campaigns 🔒 Auth

List all campaigns for the client with budget, status, and performance metrics.

Account

GET /account/profile 🔒 Auth

Get client profile including name, email, company, and logo URL.

POST /cogs/upload 🔒 Auth

Upload COGS (Cost of Goods) data via CSV. Maps ASIN → cost per unit. Used in CM calculation.

Billing

GET /billing/plans

Return plan definitions (no auth required).

GET /billing/plans → 200 { "plans": [ { "id": "starter", "name": "Starter", "price": 149, "priceMonthly": "$149/mo" }, { "id": "growth", "name": "Growth", "price": 299, "priceMonthly": "$299/mo" }, { "id": "pro", "name": "Pro", "price": 499, "priceMonthly": "$499/mo" } ] }
POST /billing/subscribe 🔒 Auth

Create a Stripe checkout session for the selected plan.

Admin

Admin routes require an admin session (separate from client sessions). Log in via POST /admin/login.

GET /admin/clients 🔐 Admin

List all clients with status, email, company name, and signup date.

GET /admin/health-scores 🔐 Admin

Health score (0–100) for all active clients with breakdown by component.

GET /admin/health-scores → 200 [ { "clientId": "test-client-001", "score": 75, "breakdown": { "cmTrend": 20, // improving CM "acosVsBreakEven": -15, // ACOS above break-even "dataFreshness": 20, // synced last 24h "amazonConnections": 20, // all 4 connected "loginRecency": 10 // logged in last 30 days (not 7) } } ]
POST /admin/invite 🔐 Admin

Pre-create an approved account and send an invite email.

Chat

POST /chat 🔒 Auth
