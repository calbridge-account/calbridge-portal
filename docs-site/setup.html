Setup Guide

Get CalBridge running locally in 10 minutes. Production deployment on an Azure Ubuntu VM takes ~30 minutes.

Prerequisites

  • Node.js v22+ (nodejs.org)
  • npm v10+
  • A Snowflake account (free trial available)
  • Amazon Developer account (for LWA/SP-API credentials)
  • Resend account (for emails)
  • Stripe account (for billing)

Clone & Install

git clone https://github.com/calbridge-account/calbridge-portal.git cd calbridge-portal npm install cp .env.example .env # then fill in your values

Snowflake Setup

Create the required tables. Run these in a Snowflake worksheet:

-- Core tables (simplified) CREATE TABLE clients ( client_id VARCHAR, email VARCHAR, name VARCHAR, company_name VARCHAR, status VARCHAR, password_hash VARCHAR, created_at TIMESTAMP, approved_at TIMESTAMP, last_login TIMESTAMP, weekly_report_enabled BOOLEAN DEFAULT TRUE ); CREATE TABLE amazon_connections ( client_id VARCHAR, connection_type VARCHAR, access_token VARCHAR, refresh_token VARCHAR, expires_at TIMESTAMP, connected_at TIMESTAMP, selling_partner_id VARCHAR ); CREATE TABLE sales ( client_id VARCHAR, asin VARCHAR, connection_type VARCHAR, order_date DATE, ordered_revenue NUMBER, shipped_revenue NUMBER, units_ordered NUMBER, created_at TIMESTAMP ); CREATE TABLE ad_performance ( client_id VARCHAR, campaign_id VARCHAR, connection_type VARCHAR, report_date DATE, spend NUMBER, sales NUMBER, orders NUMBER, impressions NUMBER, clicks NUMBER, created_at TIMESTAMP ); CREATE TABLE products ( client_id VARCHAR, asin VARCHAR, title VARCHAR, sku VARCHAR, fba_fees NUMBER, cogs NUMBER, updated_at TIMESTAMP ); CREATE TABLE contribution_margin ( client_id VARCHAR, asin VARCHAR, calc_date DATE, revenue NUMBER, ad_spend NUMBER, fba_fees NUMBER, cogs NUMBER, contribution_margin NUMBER, cm_percent NUMBER, units NUMBER, unit_cm NUMBER, unit_cm_percent NUMBER, calculated_at TIMESTAMP ); CREATE TABLE ingestion_log ( log_id VARCHAR, client_id VARCHAR, connection_type VARCHAR, job_type VARCHAR, status VARCHAR, records_written NUMBER, error_message VARCHAR, started_at TIMESTAMP, completed_at TIMESTAMP ); CREATE TABLE admin_users ( admin_id VARCHAR, email VARCHAR, name VARCHAR, password_hash VARCHAR, role VARCHAR, created_at TIMESTAMP, last_login TIMESTAMP );

Amazon OAuth Setup

Two separate OAuth apps are required:

  1. Amazon Advertising OAuth (LWA) — for Ads and DSP connections. Register at Amazon Advertising Console.
  2. SP-API OAuth — for Seller/Vendor Central. Register at Seller Central App Management.

Both require a redirect URI of https://app.teamcalbridge.com/amazon/callback/:type.

Run Locally

npm run dev # starts with nodemon hot-reload # Validate SQL schema (run before commits) npm run validate-schema # Test CM recalculation node -e " require('dotenv').config(); const { calculateContributionMargin } = require('./src/jobs/contributionMargin'); calculateContributionMargin('your-client-id', 30).then(r => { console.log('Records written:', r.recordsWritten); });"

Production Deploy

# SSH into your server ssh azureuser@your-server-ip # Pull latest code cd /home/azureuser/.openclaw/workspace git pull origin main # Install any new dependencies npm install --production # Restart PM2 with updated env vars pm2 restart calbridge-portal --update-env pm2 save

PM2 Setup

# Install PM2 globally npm install -g pm2 # Start the app pm2 start index.js --name calbridge-portal # Set up startup script (auto-start on server reboot) pm2 startup pm2 save # Common commands pm2 status # check process status pm2 logs calbridge-portal # tail logs pm2 restart calbridge-portal --update-env # restart with new .env

Nginx Config

server { listen 443 ssl; server_name app.teamcalbridge.com; ssl_certificate /etc/letsencrypt/live/app.teamcalbridge.com/fullchain.pem; ssl_certificate_key /etc/letsencrypt/live/app.teamcalbridge.com/privkey.pem; location / { proxy_pass http://localhost:3000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; proxy_cache_bypass $http_upgrade; } } server { listen 80; server_name app.teamcalbridge.com; return 301 https://$host$request_uri; }

Deploy Checklist

  • ✅ All required env vars set in .env
  • ✅ NODE_ENV=production
  • ✅ BASE_URL matches Amazon OAuth redirect URI
  • ✅ Snowflake tables created
  • ✅ PM2 process running: pm2 status
  • ✅ Nginx config valid: sudo nginx -t
  • ✅ SSL certificate active: sudo certbot certificates
  • ✅ Health check: curl https://app.teamcalbridge.com/health
  • ✅ Create first admin user in Snowflake admin_users table
