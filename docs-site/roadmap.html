Roadmap

CalBridge is in active development. Here's what's been built and what's coming next.

✅ Completed

✓
Phase 1 — Auth Portal Done
  • Signup, login, sessions (express-session)
  • Password reset via email (Resend)
  • Multi-tenant client isolation
  • Admin panel with separate session
✓
Phase 2 — Amazon OAuth Done
  • Amazon Advertising OAuth (LWA) — Ads, DSP
  • SP-API OAuth — Seller Central, Vendor Central
  • Token storage + auto-refresh
  • Connection status dashboard
✓
Phase 3 — Data Pipeline Done
  • Snowflake ingestion: sales, ad performance, products
  • 6-hour scheduler with retry logic + failure alerts
  • COGS CSV upload per ASIN
  • ingestion_log table with history
✓
Phase 4 — CM Decisioning Done
  • CM1/CM2/CM3 waterfall calculation per ASIN per day
  • Proportional ad spend attribution by revenue share
  • Break-even ACOS per ASIN (auto-calculated)
  • CM waterfall visual on dashboard overview
  • Decision engine alerts: negative margin, ACOS above break-even, spend with no sales, ACOS spikes
  • Budget pacing alerts (over/under-pacing)
  • Scale opportunity recommendations
✓
Phase 5 — Analytics & Admin Done
  • Performance tab: top 10 ASINs by revenue, daily sales trend, channel split pie
  • Advertising tab: overview KPIs, campaign-level breakdown
  • Campaigns tab: full campaign management table
  • Admin panel: client health scores (0–100), invite system, logs
  • Billing: Stripe plans + subscription management
  • Weekly HTML email reports (per client)
  • AI chat assistant with CM context

🚧 Upcoming

6
Phase 6 — One-Click Ad Actions

Write-back to Amazon Advertising API directly from the portal.

  • Pause / unpause campaigns
  • Adjust campaign daily budget
  • Modify keyword bids toward target ACOS
  • Confirmation modal before any write action
  • Action history log
7
Phase 7 — Vendor Central Full CM

Complete the Vendor CM model with co-op fees and chargebacks.

  • Co-op fee rates per ASIN
  • Damage allowance tracking
  • Chargeback history
  • Shipped COGS as Vendor revenue (not consumer price)

🔮 Future Ideas

  • Inventory forecasting — stockout risk alerts based on sales velocity
  • DSP attribution — full DSP data ingestion and ROAS reporting
  • Multi-marketplace — EU, CA, AU marketplaces alongside US
  • Client onboarding wizard — guided setup for new clients
  • Mobile app — React Native app for on-the-go insights
  • Slack/email alerts — push alerts when CM drops or budget pacing changes
  • Benchmark reports — industry ACOS/CM% benchmarks by category
